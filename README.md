# Компонент **PayCourse**

Форма оплати курсу з модальним вікном, валідацією та тост-повідомленням про успішну оплату.

## Можливості компонента

- Три чекбокси, які користувач має підтвердити перед оплатою  
- Кнопка для відкриття модального вікна  
- Модальне вікно з адаптивною формою оплати  
- Поле для введення суми оплати  
- Тост-повідомлення у правому верхньому куті  
- Автоскриття тоста через `setTimeout`  
- Можливість ручного закриття тоста  
- Оптимізовані чекбокси й анімації натискання  
- Покращена стилізована кнопка «Оплатити курс»  
- Повністю адаптивна верстка під мобільні пристрої  

## Основна логіка

- Кнопка «Оплатити курс» стає активною лише після проставлення всіх чекбоксів  
- Після сабміту форми модальне вікно закривається  
- Показується тост-повідомлення на 3,5 секунди  
- Тост можна закрити вручну  
- Усі поля модалки адаптивні й займають 100% ширини контейнера
